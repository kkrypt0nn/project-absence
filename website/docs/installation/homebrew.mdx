---
title: Homebrew
description: Install Project Absence with Homebrew
---

You need to have [Homebrew](https://brew.sh) installed. You can then install using

```bash
brew install kkrypt0nn/tap/project-absence
```

The Homebrew Formula is available [here](https://github.com/kkrypt0nn/homebrew-tap/blob/main/Formula/project-absence.rb).
