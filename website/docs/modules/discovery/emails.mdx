This module will perform a passive discovery of new emails via multiple runners.

## Dork Runner

This runner will use a search engine and dorking techniques. The available parameters are:

| Parameter       | Description                                             | Default  |
| --------------- | ------------------------------------------------------- | -------- |
| `search_engine` | The search engine to use. Can be: `ecosia` or `google`. | `ecosia` |
