This module will perform a passive discovery of (previous) endpoints via multiple runners.

## Wayback Machine Runner

This runner will use the Wayback Machine to find (previously) existing endpoints. The available parameters are:

| Parameter | Description                                                   | Default |
| --------- | ------------------------------------------------------------- | ------- |
| `timeout` | The timeout, in seconds, to use when requesting the endpoint. | `30`    |
