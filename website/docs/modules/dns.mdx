This module gets data about the DNS entries of the domain, and flags certain keywords as interesting.

The available parameters are:

| Parameter              | Description                                       | Default                                    |
| ---------------------- | ------------------------------------------------- | ------------------------------------------ |
| `record_types`         | The type of DNS records to request for.           | `["a", "aaaa", "caa", "mx", "soa", "txt"]` |
| `interesting_keywords` | The interesting keywords per record type to flag. | `mx = ["protonmail.ch"]`                   |
