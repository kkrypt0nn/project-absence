This module gets some information about the infrastructure of the domain, such as possible web-server, CDN used, etc.

It gathers the following data about the TLS certificate:

- Serial
- Subject
- Issuer
- Not Before & Not After
- Expires (in seconds)
- Key Type
- SAN

It also gathers what cloud provider the domain is likely using, based on headers and/or header values.

It also gathers security relevant headers such as HSTS, CSP, etc.
