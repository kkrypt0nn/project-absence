Project Absence supports Lua files for scripting. Each Lua script acts as a module and must return a table containing specific required methods.

## Minimal script structure

Every Lua script must:

- Return a table (essentially the module)
- Implement a set of required pre-defined methods
  - These methods must return pre-defined values

Example:

```lua
MyScript = {}

function MyScript:description()
    return "This example module/script will just print 'Hello from Lua!' when a 'Ready' event has been emitted."
end

function MyScript:subscribers()
    return { "ready" }
end

function MyScript:execute()
    println("$[fg:blue]$[effect:bold]Hello from Lua!$[reset]")
    return true
end

return MyScript
```

## Required methods

### `description() -> string`

Returns the description of your script.

### `subscribers() -> table<string>`

Returns a list of event names your script listens to.

### `execute(...) -> boolean`

Called when one of your subscribed events is emitted.

Must return:

- `true` on success
- `false` on failure
