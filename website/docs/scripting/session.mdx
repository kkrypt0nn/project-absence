---
title: Session
description: Access runtime state and interact with the database.
---

The `session` parameter is passed into your `execute()` function.

```lua
function MyScript:execute(session, event)
```

The session provides access to internal runtime state and the database.

## Available methods

### `database() -> LuaDatabase`

Returns a `LuaDatabase` object that allows you to modify existing nodes.

See the [Database](database.mdx) page for all available methods.

### `discover_domain(domain: string)`

Publishes a new `discovered:domain` event.

```lua
session:discover_domain("example.com")
```

### `http_get(url: string, user_agent: string?) -> string`

Makes a new HTTP GET request to the URL with the given user agent, or a random one if not set, and returns the response body.

```lua
local response = session:http_get("https://example.com")
```
